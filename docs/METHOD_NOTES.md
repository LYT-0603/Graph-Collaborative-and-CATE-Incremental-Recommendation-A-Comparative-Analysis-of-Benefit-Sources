# 方法与复现边界

## 半合成机制

脚本 `run_full_experiment.py` 的 `simulate` 是当前生成机制的权威定义。先根据活跃度、流行度、匹配、类别亲和与图亲和生成处理概率，按 Bernoulli 分配处理；再指定两个潜在结果概率并按实际处理采样结果。模型只拟合事实 A/Y，评价器保留 e、p0、p1 与 tau。p1 上限为 0.90，保存的 tau 使用最终 p1 减 p0。

feature_effect 的自然购买依赖图亲和，效应由活跃度与类别亲和主导；graph_effect 的效应包含 LightGCN 协同分数百分位。两个环境的 p0 也不同，不能声称仅改变 tau。生成器使用参赛 LightGCN 的预训练打分，因此其优势不是独立生成器下的架构验证。后续应使用独立共享邻居统计或其他模型生成器检验稳健性。

## 训练方案

MF：32 维，BPR 50 轮，学习率 0.025。LightGCN：从 MF 训练终点热启动，再以学习率 0.001 在两层图传播上 BPR 微调 50 轮。此处不存在严格相同的从头训练预算。

两种表示冻结后分别拟合共享隐藏层的双结果头，实际处理分支提供二元交叉熵损失，验证集事实损失选择早停。两种排序复用各自同一个已拟合头。该代码没有交叉拟合、倾向模型拟合、DR 伪结果或第二阶段 DR 回归。讨论 DR 文献不等于完成 DR 实验。

历史图在标签生成前已经存在，可以包含测试用户的历史连接，所以这是基于固定历史图的传导式评价；测试处理结果标签仍被隔离。它不是完全未见用户或商品的冷启动评价。

## 评价目标

策略逐用户选择相同数量商品，主评价采用真概率而非随机单次 Y，以减少评价噪声。名单自然购买加名单增量等于名单推荐后期望购买。若评价完整候选全集的干预后总购买，则要加入所有未被推荐候选的自然购买；在无干扰条件下，它等于完整候选自然购买常数加名单增量。两个指标不能混称。

真实 CATE 排序在固定 Top-K 和无干扰设定下最优增量；实际估计 CATE 排序可能因估计误差落后。概率 Oracle 与 CATE Oracle 对应不同目标，regret 需在同一目标下计算。当前机制效应非负，没有验证负效应、不推荐动作和商品替代。

## 验证和后续

主结果来自一个固定历史图、一个固定划分以及五个模拟/监督随机种子，不能推断跨图或真实线上泛化。未来工作包括：独立生成机制、统一优化预算、更多种子、不同数据集、多 core 阈值、度保持重连、交叉拟合 DR 与随机曝光策略评价。仅有曝光的日志仍需要识别假设，不自动等于随机化数据。
